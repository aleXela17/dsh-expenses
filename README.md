# dsh-expenses

Token usage and cost panel for DeepSeek Harness sessions.
Панель расхода токенов и стоимости по сессиям DeepSeek Harness.

## Что показывает

Плагин читает журнал сессий DSH и сводит его в таблицу: токены на входе, кэш,
выход, число запросов к модели и вызовов инструментов, стоимость в рублях.
Рядом с таблицей — остаток и суммарные списания на Polza, чтобы цифру можно было
сверить с биллингом.

## Тарифы и кэш

Стоимость считается по живому каталогу Polza: хост-половина плагина раз в
30 минут забирает `GET https://polza.ai/api/v1/models` (там же лежат цены
кэш-чтения и кэш-записи, которых нет на странице модели) и отдаёт их браузеру
через `GET /api-expenses/prices`. Ключ берётся из `POLZA_AI_API_KEY`
(переменная окружения → сервис credentials → `~/.dsh/.credentials.yaml`).

Четыре компонента тарифа считаются раздельно: вход, выход, чтение кэша, запись
кэша. Это принципиально: в длинной агентской сессии кэш-чтения дают около трёх
четвертей счёта, а тариф, который их игнорирует, занижает стоимость в разы.
Например, 1 млн входа + 1 млн выхода + 100 млн кэша на `deepseek-v4.1-flash`
стоят 104,85 ₽, из которых 83,33 ₽ — кэш.

Если каталог недоступен, панель показывает встроенную таблицу (значения
`top_provider.pricing` на 2026-11-13, включая кэш) и помечает источник строкой
«встроенная таблица».

Проекция хранит кэш-токены с `stateVersion: 3`; чекпоинты версии 2 реестр
пересчитывает по журналу, поэтому исторические сессии тоже показывают кэш.

## Проверка

```bash
node test/host.mjs     # проекция + маршрут цен; ходит в живой API Polza
node test/client.mjs   # рендер панели на мини-React, без сети
```

## Установка

Плагин ставится как бандл профиля DeepSeek Harness:

1. добавьте зависимость в `package.json` профиля:

   ```json
   "@local/dsh-expenses": "github:aleXela17/dsh-expenses#<commit>"
   ```

2. добавьте `@local/dsh-expenses` в список `dsh.profile.bundles` того же файла;
3. перезапустите DSH.

Для итерации вместо пина можно указать `link:<путь к рабочей копии>` — правки
в `client.js` подхватываются после перезагрузки окна.
